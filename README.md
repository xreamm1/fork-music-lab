# Fork Music Lab

Набор интерактивных музыкальных экспериментов на основе Web Audio API.

## MP3 в ноты

Главная страница `index.html` — редактор с импортом MP3/WAV, распознаванием основной мелодии и приблизительного темпа, редактируемой сеткой, прослушиванием и экспортом MIDI. Файл обрабатывается локально без отправки на сервер. Сборка и установка зависимостей не нужны.

Запуск из корня репозитория:

```sh
python -m http.server 8000
```

Открой `http://localhost:8000`. Также можно разместить файлы на статическом хостинге, например GitHub Pages (ветка `main`, папка `/`). Двойной щелчок по HTML не подходит: анализ выполняется в Web Worker.

Лимиты: 30 МБ, 90 секунд. Распознаётся одна основная нота в каждый момент времени, лучше всего на чистой записи одного инструмента. Полифония, инструменты, ударные и точная аранжировка не восстанавливаются. Автоматический темп приблизительный, его можно поправить вручную. «Применить темп к сетке» сбрасывает ручные правки и заново размещает распознанные ноты.

Проверка алгоритма: `node mp3-import/analysis.test.js`.

## Эксперименты

- `arpeggios` — арпеджио
- `chords` — аккорды
- `harmonics & strings` — гармоники и струны
- `melodymaker` — редактор мелодий
- `pianoroll` — пианоролл
- `soundspinner` — работа со звуком
- `soundwaves` — звуковые волны
- `spectrogram` — спектрограмма

Инструкции по сборке находятся в README соответствующего эксперимента.
